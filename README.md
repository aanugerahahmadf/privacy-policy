# Kebijakan Privasi - Wedding Organizer

Repositori ini menyimpan Kebijakan Privasi untuk aplikasi mobile dan platform backend (Laravel) pada sistem **Wedding Flower Decorations Content Based Image Retrieval (CBIR)**.

## Dokumen

| Komponen | Halaman |
|----------|---------|
| Aplikasi Mobile (Flutter) | [Kebijakan Privasi - Aplikasi Mobile](mobile-app/index.html) |
| Platform Backend (Laravel / Website / Admin / API) | [Kebijakan Privasi - Backend](laravel/index.html) |
| Dokumen gabungan (Markdown) | [privacy-policy.md](privacy-policy.md) |

## Penggunaan

Halaman HTML dapat di-hosting langsung (misalnya melalui GitHub Pages) dan dijadikan URL Kebijakan Privasi untuk keperluan publikasi aplikasi di Google Play Store / App Store.

Sesuaikan bagian **Kontak** (nama perusahaan/developer, email) sebelum dipublikasikan.
